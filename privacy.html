Privacy Policy

This application is used privately to access authorized Google Drive accounts through Rclone.

Google Drive data is accessed to list, read, create, modify, and delete files as directed by the authorized user.

Rclone runs locally on the user's Windows computer. Authentication credentials and temporary file caches are stored locally.

This application does not operate a separate server collecting or selling Google user data.

Access can be revoked through the user's Google Account security settings. Local credentials and cached files can be deleted by the user.
